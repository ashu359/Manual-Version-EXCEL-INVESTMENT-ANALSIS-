📊 Investment Performance Analysis – Excel Dashboard

📁 Project Overview

This Excel project presents a comprehensive investment analysis dashboard designed to track financial performance across multiple asset classes. It transforms raw investment data into interactive insights for better decision-making.

❓ Problem Statement

"To analyze investment performance across different asset types, sectors, and risk levels, and identify high-return opportunities while understanding risk distribution and advisor effectiveness."

📊 Data Structure

📑 Sheet 1: Investment Data

Includes detailed records of investments:
Investment Type (Crypto, Equity, Debt, ETF, Gold, Mutual Fund)
Sector (Banking, Energy, FMCG, Healthcare, IT)
Status (Active / Closed)
Risk Level (High, Medium, Low)
Amount Invested, Returns, Duration

🎯 Key Features

✅ KPI Dashboard (Total Return, Avg Return %, Total Investment)
✅ Advisor Performance Analysis
✅ Sector-wise Investment Allocation
✅ Risk Level Distribution
✅ City-wise Return Comparison
✅ Interactive Filters (Slicers)
✅ Dynamic Charts & Visual Insights

📈 Dashboard Insights

💰 Total Investment: 302M+ with ~14% avg return
📊 Balanced allocation across sectors (20% each)
🏙️ Delhi shows highest returns among cities
⚖️ Medium risk investments provide better returns
📉 Gold & Equity show stable performance trends

🧠 Analysis Capabilities

You can use this dashboard to:
Compare returns across investment types
Analyze sector allocation strategies
Evaluate advisor performance
Understand risk vs return relationship
Track active vs closed investments

Open the Excel file

Explore charts for insights
Analyze KPIs for decision-making
